# Шрифты для локального контура

Положите сюда файлы шрифта Open Sans или Noto Sans в формате WOFF2 / TTF:
- `OpenSans-Regular.woff2` (400)
- `OpenSans-SemiBold.woff2` (600)
- `OpenSans-Bold.woff2` (700)

В файле `index.html` уже прописаны правила `@font-face` с локальным поиском. Если локальных файлов нет, автоматически используется системный гуманистический гротеск без обращения к внешним CDN.
